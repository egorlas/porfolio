# pofolio

Personal portfolio landing page for Vuong Ngo (egorlas), built as a lightweight static site.

## Local preview

Run any static file server from the project root and serve `dist/`.

```powershell
python -m http.server 4173 --directory dist
```

Then open `http://localhost:4173`.

## Structure

- `dist/index.html` — content and document structure
- `dist/styles.css` — responsive visual system and motion
- `dist/script.js` — navigation, command palette and subtle interactions
- `dist/assets/` — portrait, identity visuals and downloadable CV
